## Background

In this sample project, we use Specmatic to contract test a Spring Boot BFF that exposes a GraphQL API. Specmatic auto-generates tests from [the Products BFF GraphQL SDL](https://github.com/specmatic/specmatic-order-contracts/blob/main/io/specmatic/examples/store/graphql/products_bff.graphqls), and the BFF calls a Specmatic-managed mock created from [the Order API OpenAPI spec](https://github.com/specmatic/specmatic-order-contracts/blob/main/io/specmatic/examples/store/openapi/api_order_v5.yaml).

* [Products BFF GraphQL SDL](https://github.com/specmatic/specmatic-order-contracts/blob/main/io/specmatic/examples/store/graphql/products_bff.graphqls) is used for running contract tests against the BFF.
* [Order API OpenAPI spec](https://github.com/specmatic/specmatic-order-contracts/blob/main/io/specmatic/examples/store/openapi/api_order_v5.yaml) is used for stubbing the backend REST dependency.

## Why Specmatic

* **Auto-generated tests from your API spec** - Specmatic reads your GraphQL SDL and generates test cases automatically. No hand-written contract test cases to maintain.
* **Intelligent service virtualisation** - Specmatic generates realistic REST mocks from the dependency spec, so the BFF can be tested without a real backend service.
* **Backward compatibility detection** - Specmatic compares spec versions and flags breaking changes before they reach production.
* **GraphQL schema compliance** - Specmatic validates queries, mutations, and schema compliance from your GraphQL SDL.

## Run Contract Tests

### Prerequisites

* JDK 17+
* Maven 3.9+ or the included Maven Wrapper
* A valid `SPECMATIC_LICENSE_KEY` for Specmatic Enterprise
* Access to `io.specmatic.enterprise:executable-all:1.19.1`

### Using The Build Tool

For **Unix based systems** and **Windows PowerShell**:

```shell
./mvnw test
```

For **Windows Command Prompt**:

```shell
mvnw.cmd test
```

First run may take 1-2 minutes as Specmatic clones the configured contract repository. Subsequent runs are fast, cached in `.specmatic/`.

[specmatic.yaml](specmatic.yaml) configures the GraphQL contract tested against this BFF and the REST backend dependency mocked by Specmatic.

#### View Specmatic Test Reports

After running the contract tests, you can view the HTML report generated by Specmatic in [build/reports/specmatic](build/reports/specmatic/). The same directory also contains the CTRF output for CI tooling.

### Test Modes

This sample ships with `schemaResiliencyTests: all` which runs the full test suite including negative/boundary tests. You can adjust the mode in `specmatic.yaml`:

| Mode | What it does |
|------|-------------|
| `none` | Runs tests from named examples only (fastest) |
| `positiveOnly` | Adds all valid input combinations |
| `all` | Adds negative/boundary tests and expects contract-valid error handling |

To change, update `specmatic.yaml`:

```yaml
specmatic:
  settings:
    test:
      schemaResiliencyTests: none
```

## How It Works

```text
BFF GraphQL SDL -> specmatic.yaml -> Specmatic generates requests to your BFF -> Your BFF calls dependency (Specmatic mock) -> Specmatic validates both sides
```

When you run `./mvnw test`, Maven copies the Specmatic Enterprise executable, starts the Spring Boot BFF, and runs `java -jar target/specmatic/specmatic-enterprise.jar run-suite --config specmatic.yaml`. Specmatic reads `specmatic.yaml`, fetches the configured contracts, starts the REST dependency mock, generates GraphQL requests, and validates the BFF responses against the SDL.

## Configuration

| Environment Variable | Default | Description |
|---------------------|---------|-------------|
| `SUT_PORT` | `8080` | Spring Boot application port |
| `SUT_HOST` | `127.0.0.1` | Host used by Specmatic GraphQL tests |
| `SUT_BASE_URL` | `http://127.0.0.1:8080` | Base URL used by Specmatic tests |
| `STUB_BASE_URL` | `http://127.0.0.1:8090` | REST backend mock URL started by Specmatic |
| `BACKEND_AUTHENTICATE` | `sample-api-key` | Outbound `Authenticate` header required by the REST dependency |
| `BACKEND_IDEMPOTENCY_KEY` | `00000000-0000-0000-0000-000000000001` | Outbound `Idempotency-Key` header used when creating products |

## Project Structure

| File | Purpose |
|------|---------|
| `specmatic.yaml` | Contract test configuration for the GraphQL BFF and REST dependency mock |
| `src/main/resources/graphql/schema.graphqls` | GraphQL SDL implemented by the Spring GraphQL app |
| `src/main/java/...` | Application source code, resolvers, scalar config, and REST dependency client |
| `scripts/test.sh` | CLI-mode adapter that starts the app and runs Specmatic Enterprise directly |
| `Dockerfile` | Production container image |
| `.github/workflows/ci.yml` | CI pipeline: contract tests and Docker build |
