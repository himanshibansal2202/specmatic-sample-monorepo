## What is this?

This monorepo contains working samples generated by the [Specmatic Sample Generator Skill](https://github.com/himanshibansal2202/Specmatic-sample-generator-skill) — an AI skill for Claude Code and OpenAI Codex. Each sample demonstrates how to integrate Specmatic contract testing into a real application, using the [specmatic-order-contracts](https://github.com/specmatic/specmatic-order-contracts) as the contract source.

## How to Run Any Sample

Each sample is self-contained. Enter its directory and run the test command:

```bash
# Python FastAPI (needs Java 17+ and Python 3.12)
cd backend-rest-python-fastapi
pip install -r requirements.txt
pytest test -v -s

# Java Spring Boot (needs Java 17+)
cd backend-rest-java-spring-boot
./mvnw test

# TypeScript Express Backend (needs Node 18+ and Docker)
cd backend-rest-typescript-express
npm install && npm test

# BFF Java (needs Java 17+)
cd bff-rest-java-spring-boot
./mvnw test

# BFF GraphQL Java (needs Java 17+)
cd bff-graphql-java-spring-boot
./mvnw test

# BFF TypeScript Express (needs Node 20+ and Docker)
cd bff-rest-typescript-express
npm install && npm test
```

Set `SPECMATIC_LICENSE_KEY` before running if the contract repo doesn't include a trial license.
